## 🚀 Selected Projects

### 🛒 Tarumi — Smart Shopping Cart for Wheelchair Users

A smart shopping cart designed to assist wheelchair users by combining
**computer vision, embedded systems, autonomous tracking, and web technologies**.

**Key components**
- YOLO-based wheelchair and product detection
- SORT-based user tracking
- Raspberry Pi 5 + Arduino motor control
- Multi-threaded real-time processing
- Web-based shopping cart interface
- Bluetooth manual control application

[![View Repository](https://img.shields.io/badge/View_Repository-Tarumi-181717?logo=github)](https://github.com/augustinus2000/Tarumi)

---

### ✨ GreyoDream — AI Illustrated Diary

An Android diary application that transforms written diary entries into
**AI-generated illustrations** and stores them together as visual memories.

**Key components**
- Native Android application in Java
- Room Database
- Retrofit-based REST API communication
- FastAPI image-generation backend
- Generative AI integration
- Complete diary CRUD workflow

[![View Repository](https://img.shields.io/badge/View_Repository-GreyoDream-181717?logo=github)](https://github.com/augustinus2000/GreyoDream)
